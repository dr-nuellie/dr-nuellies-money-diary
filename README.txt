My Money Diary — updated app package

Install by replacing the files in your existing app hosting folder at the SAME URL/origin. Your existing finances are stored in browser local storage under that origin; always export a backup before updating and do not clear site data.

Changes:
- New plum wallet/growth logo: app icons, favicons, headers and unlock page.
- Installed-PWA full-viewport unlock screen with mobile safe-area support.
- Unlock title uses the selected app theme's font.
- Investment value-at-date calculator in Investments (simple, compound and fixed monthly return calculations), with optional saved-investment selection.

Run via HTTPS or from the installed PWA for service worker and biometric functionality. Opening index.html as a local file has browser limitations.
See TEST_REPORT.md for specific checks and limitations.
