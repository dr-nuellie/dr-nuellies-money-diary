My Money Diary — investment valuation, logo and subscription-edit update.
Unzip and deploy the full set of application files together on the SAME website/origin as the previous build to preserve locally stored financial data.
Export a backup of your financial data before deploying. Changes to storage location or clearing browser storage may remove records.
For a monthly rollover investment, edit the investment to select "Monthly (% per month)" and "Reinvest (add to principal)". Then choose "Portfolio value as at" to view each value and the combined total.
